# Dental_Root_Length_Estimation_Web_Application
A deep learning-powered web application for automated analysis of dental radiographs. The system detects primary molars using YOLO and estimates root length through multiple AI-based prediction models, providing annotated visualizations and quantitative measurements via an intuitive Flask web interface. Designed for clinical research, educational purposes, and computer-aided dental diagnosis.
